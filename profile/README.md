Medhyom builds software tools. We start where things are tangled.

### How we work

- **Start with the tangle.** Data, rules and choices, knotted together. That is where we begin.
- **Find the structure.** Every hard problem has an order in it. We work until it shows.
- **Build only that.** A tool that follows the structure stays exact, simple and quiet.
